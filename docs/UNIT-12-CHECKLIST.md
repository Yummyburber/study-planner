# Unit 12 MVP Delivery Checklist

## Application
- [ ] Install dependencies and run locally.
- [ ] Test class create, edit, and delete.
- [ ] Test assignment create, edit, delete, and completion.
- [ ] Confirm data persists after restarting the server.
- [ ] Check responsive layout.

## GitHub
- [ ] Commit MVP on `feature/mvp-foundation`.
- [ ] Push the feature branch.
- [ ] Open a pull request into `main`.
- [ ] Review and merge the pull request.
- [ ] Confirm README reflects the actual tested state.

## Docker
- [ ] Build image with `docker compose up --build`.
- [ ] Open http://localhost:8080.
- [ ] Test create and update operations in the container.
- [ ] Confirm the named volume preserves SQLite data.

## Google Cloud
- [ ] Attempt deployment to Google Cloud Run.
- [ ] Record the deployed URL, even if the deployment is not yet working.
- [ ] Record any errors and the attempted fix in Confluence.

## Jira and Confluence
- [ ] Update Jira stories and tasks to match implemented work.
- [ ] Record time spent accurately.
- [ ] Document architecture, setup, testing, AI use, and deployment attempt in Confluence.
- [ ] Verify the professor can access both Jira and Confluence links.
